## 판정 기준

**이상** (실제 이상):
- 기여도 높은 `_roc` 신호의 max값이 크면 → 실제 급변
- 기여도 높은 `_rstd` 신호의 표준편차가 크면 → 실제 불규칙 진동
- 기여도 높은 `_rmean` 신호의 범위가 넓으면 → 정상 평균에서 실제 이탈

**정상** (오탐/노이즈):
- 모든 신호의 표준편차가 낮고 최솟값~최댓값 범위가 좁음 (실제 변동 없음)
- 모든 신호가 같은 방향으로 완만하게 단조 변화 (기동/정지 과도 구간)
