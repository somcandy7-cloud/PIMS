## 핵심 판단 지식

### IF 점수 해석
- score는 **항상 음수**입니다. 음수 자체는 판단 근거가 될 수 없습니다.
- **score가 낮을수록(더 큰 음수) 이상일 가능성이 높습니다.**

| score 범위 | 의미 |
|-----------|------|
| ≤ -0.5 | 매우 강한 이상 신호 |
| -0.5 ~ -0.3 | 강한 이상 신호 |
| -0.3 ~ -0.15 | 이상 가능성 있음 |
| > -0.15 | 불확실 |

### 신호 접미사 해석
- `_roc` = 변화율 (Rate of Change). 기여도가 높으면 해당 신호가 **급격히 변화**했다는 뜻.
- `_rstd` = 구간 변동성. 기여도가 높으면 해당 신호가 **불규칙하게 요동**쳤다는 뜻.
- `_rmean` = 평균 이탈. 기여도가 높으면 해당 신호가 **정상 평균에서 벗어**났다는 뜻.

### 기여도(%) 해석
- 기여도 = 이번 이상 점수에서 해당 신호가 차지한 원인 비율
- 기여도 96% → 그 신호 하나가 이상의 원인 대부분
- 나머지 신호가 기여도 0%인 것은 "정상"의 증거가 **아닙니다** — 단지 주원인이 아닌 것뿐입니다

## 판정 기준

### 이상으로 판정할 때
- `_roc` 기여 신호의 context 통계에서 값의 범위(max-min)가 크거나 평균이 높은 경우 → 실제 급변
- `_rstd` 기여 신호의 표준편차(std)가 높은 경우 → 실제 불규칙 변동
- score가 -0.5 이하이고 context 통계도 이를 뒷받침하는 경우

### 정상으로 판정할 때
- 모든 신호의 context 통계에서 값 범위가 좁고 표준편차가 낮은 경우 (실제 변동 없음)
- 모든 주요 신호가 동일 방향으로 완만하게 단조 변화하는 경우 (기동/정지 과도 구간)
- score가 -0.15보다 크고 통계도 이상 패턴이 없는 경우

### ❌ 금지된 추론
- "score가 음수이므로 정상이다" — score는 항상 음수입니다
- "기여도 0% 신호가 많으므로 신뢰할 수 없다" — 기여도 0%는 주원인이 아닌 것이지 정상의 증거가 아닙니다
- "기여도가 한 신호에 집중됐으므로 정상이다" — 단일 신호 급변도 실제 이상일 수 있습니다
